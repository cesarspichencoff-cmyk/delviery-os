# Exemplos — Passaporte, Evidência, Contestação V0.2

> Sintético. Delivery Pleno `PART-DP-07`.  
> Contestação ≤ **1 min** para abrir. Validação 30–45 s quando clara.

---

## 1. Passaporte V0 (1 página / 1 face)

| Campo | Valor sintético |
|---|---|
| trilha_atual | Delivery Pleno · Onda 1 |
| proximo_passo | No pico: comunicar estado+impacto+ação (sem “cadê?”) |
| competencias_demonstradas | C-DJ03 (B) · C-T02 (B) |
| evidencia_necessaria | 1 observação C-T03 no turno **ou** re-caso E01 |
| validador_possivel | DS do turno → se dúvida, LE |
| foco_desenvolvimento | Escalonamento com contexto |
| status_contestacao | nenhuma |

**&lt;10 s:** onde estou · o que faço · o que demonstrar · quem valida · como contestar (verso).

---

## 2. Evidência de uma linha (30–45 s)

### Positiva (exemplo)
```text
EV-021 | C-T02 | Pico | Ajudou montagem; confirmou dono em voz alta; kit conferido com dono | ok | DS-A | aprovada | contestável
```

### Desenvolvimento (exemplo)
```text
EV-022 | C-T03 | Pico | Usou só "cadê?"; após dica, refez com estado+impacto | parcial | DS-A | aprovada c/ foco | contestável
```

**Proibido:** “maduro”, “comprometido”, “perfil”.

---

## 3. Fluxo do validador (&lt;1 min se claro)

1. Ler 1 linha.  
2. Meu escopo?  
3. É fato observado?  
4. Validar / devolver / insuficiente.  
5. Atualizar `proximo_passo` se preciso **ou** reconhecer.  
6. Lembrar contestação.  
7. Pronto.

Sensível ($ / acusação): **não** criar+validar+aprovar sozinho.

---

## 4. Contestação em papel (abertura ≤1 min)

### Verso do Passaporte / ficha
```text
CONTESTO evidência: EV-____
Ponto objetivo (1 linha): ________________________________
Data: __/__  Participante: ____  Recebido: ____
Status evidência: SUSPENSA (não consolidar no Passaporte)
```

### Fluxo
1. Assinala contestação (sem confronto obrigatório com o validador original).  
2. Evidência **suspensa**.  
3. Validador **substituto** ou LE revisa só o ponto objetivo.  
4. Resultado: **corrigida** | **mantida com fundamento** | **rejeitada a contestação** (com 1 linha).  
5. Versão anterior grampeada / riscada com data (rastreável).  
6. Passaporte: durante suspensão **não** mostra como consolidada.

### Exemplo
- EV-002: “Não ajudou no pico.”  
- Contesta: “Estava em Quentes com 2 pedidos.”  
- Revisão DS: confirma presença em Quentes; comunicação à bancada não observada.  
- EV-002v2 factual; v1 arquivada “incompleta”.  
- Sem punição; foco permanece comunicação se couber.

---

## 5. Revisão semanal de equilíbrio (facilitador)

Duas perguntas (folha H/J do kit):

1. O que precisa ser desenvolvido?  
2. O que funcionou e deve ser repetido?

Se a semana só tiver falhas/correções → **risco registrado** (não inventar elogio).
