## B3-CASE-001 — Omissão de kit recorrente

| Campo | Conteúdo |
|---|---|
| período | Múltiplos meses 2024 (Ago, Out, Nov, Dez, Fev, Mai, Jun) |
| situação | Reclamações listam “Faltou kit” de forma repetida entre meses |
| fonte | B3-DOC-001, 002, 003, 005, 006, 007, 008 (listas de erros delivery) |
| evidência | Ocorrência listada · sem denominador de pedidos |
| princípio | Conferência / embalagem / excelência em atendimento |
| decisão / resultado | Não documentados no PDF |
| aprendizado candidato | Kit como checklist obrigatório de fechamento de sacola |
| limitações | Sem taxa; possível sub/super contagem; sem praça |
| validação César | Sim — se vira procedimento padrão |

**Destinos:** formação · procedimento · embalagem · conferência

## B3-CASE-004 — Cancelamento por atraso vs cancelamento logístico

| Campo | Conteúdo |
|---|---|
| período | Jan/2023; Fev–Dez/2024 |
| situação | Motivos misturam atraso, não localizado, área de risco, veículo, sistema, item indisponível |
| evidência | Tabelas de motivo de cancelamento |
| princípio | Separar eixos nativo (atraso/logística) vs falha de loja |
| aprendizado | Não tratar todo cancel como “erro de cozinha”; alinhar com L2C (nativo vs comunicação) |
| limitações | Definição iFood; sem tempo de preparo no PDF |
| validação César | Sim (linguagem de briefing) |

**Destinos:** briefing · dados e medição · logística · atendimento

## B3-CASE-005 — Pressão de fim de noite (faixa 22–00 no relatório)

| Campo | Conteúdo |
|---|---|
| período | Todos os PDFs com slide de horários |
| situação | Relatório inclui faixa **22:00–00:00** como horário de pedidos |
| evidência | Dado/gráfico de horário |
| princípio | Regra atual L2C: fluxo normal &lt; 23:00; after-23 separado |
| aprendizado | Atualizar templates de relatório para **não** misturar madrugada com jantar operacional |
| limitações | Gráfico sem números estáveis em vários PDFs |
| validação César | Sim — padrão de relatório interno |

**Destinos:** dados e medição · DeliveryOS futuro · procedimento de reporte
