# Boas Práticas e Recuperação — L5

> O programa **não** se constrói só com falhas.  
> Recuperação aqui é majoritariamente **lacuna de dado** (sem respostas no export).

---

## 1. O que preservar (sinais positivos)

A partir de tags e textos positivos (agregado):

| Sinal | Evidência agregada | Prática a preservar |
|---|---|---|
| Sabor / comida saborosa | Tema dominante em 5★ | Manter padrão de peixe e preparo; reforçar no briefing |
| Embalagem elogiada | Tags “Boa embalagem” / sustentável | Padronizar montagem e lacre |
| Aparência | “Boa aparência” | Apresentação de uramaki/niguiri |
| Quantidade | “Boa quantidade” | Expectativa de porção estável |
| Temperatura | “Temperatura certa” | Fluxo de saída quentes/frios |
| Atendimento cordial | Poucos textos, alto impacto quando aparece | Linguagem humana nas respostas (quando existirem) |

**Boa prática de formação:** usar **elogios específicos** (sabor + embalagem + aparência) como âncora do que “bom” significa na casa — não apenas “nota 5”.

## 3. Padrão institucional de resposta (proposto, não treinado aqui)

Quando houver resposta futura:

1. Reconhecer a percepção (sem ironía).  
2. Não culpar cliente, motoboy ou colega **sem evidência**.  
3. Separar o que é responsabilidade da loja do que é hipótese.  
4. Oferecer próximo passo claro (reenvio, crédito, investigação).  
5. Não prometer o incontrolável.  
6. Fechar ciclo e registrar tipo de recuperação.  
7. Preservar privacidade (sem repetir dados sensíveis).

Classificações futuras: adequada · parcial · inadequada · defensiva · genérica · sem ação · boa recuperação · ausente.

## 4. Micropraticas ligadas aos temas negativos L5

| Tema | Prevenção | Recuperação típica (conceito) |
|---|---|---|
| Item faltante / kit | Checklist de sacola | Reenvio ou crédito conforme política |
| Item trocado | Conferência de combinado | Correção + desculpas |
| Qualidade/frescor | Padrão de corte/armazenagem | Escuta + política de reposição |
| Porção/preço | Clareza no cardápio | Expectativa, não “erro” automático |
| Embalagem | Lacre e montagem | Orientação + cortesia se cabível |

## 5. O que **não** fazer

- Usar nota baixa para punir pessoa  
- Responder no automático sem ler o texto  
- Tratar toda nota 3 como falha grave  
- Afirmar recuperação bem-sucedida sem evidência  
- Publicar textos de clientes em materiais internos sem anonimizar
