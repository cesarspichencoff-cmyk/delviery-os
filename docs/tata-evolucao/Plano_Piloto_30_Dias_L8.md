> Piloto da **Onda 1** com hard caps. **Independente de aplicativo.**

---

## 0. Propósito e anti-punição

Formação, autonomia e melhoria — **não** disciplina.  
Registrar positivos. Contestação possível. Falha isolada ≠ diagnóstico.

---

## 1. Hard caps (obrigatórios)

| Cap | Valor |
|---|---|
| Tempo / funcionário / semana | **≤ 40 min** |
| Tempo LE (ou validador principal) / semana | **≤ 75 min** se equipe **≤ 12** |
| Equipe &gt; 12 | **Redistribuir** validação (DS/AO); registrar necessidade |
| Microlições / semana | **≤ 2** |
| Caso ou simulação principal / semana | **≤ 1** |
| Validação formal / funcionário / semana | **≤ 1** |
| Registro de evidência | **&lt; 1 min** · **sem** redação longa obrigatória |
| Casos ativos biblioteca | **10** (fixos) |
| Formações no piloto base | **F1 + F2 núcleo** apenas |
