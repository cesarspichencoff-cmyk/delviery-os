## CASE-PROT-01 — Item faltante após a saída

| Campo | Conteúdo |
|---|---|
| Base | O01 · F2 · P2/P6 tipos |
| Funções | SAC · CX · LE se $ |
| Comp | C-SAC* · C-CX04 |
| Tempo | **8–10 min** em grupo |

### Contexto
Pedido saiu. Cliente: faltou item. Pós-pico leve.

### Disponível / ausente
**Há:** relato, status saído, regra $ provisória.  
**Não há:** foto, causa confirmada, comanda na mão no 1º segundo.

### Opções
| # | Opção | Risco |
|---|---|---|
| A | Desconto imediato e encerra | $ sem A; sem investigação |
| B | “Vamos ver” sem dono/prazo | Ciclo aberto |
| C | Reformula; fato vs hipótese; checagem; retorno com tempo; $ só com LE; registra e fecha | Tempo e disciplina |
| D | Pede evidência e **continua** o ciclo com prazo (não some) | **Parcial** se virar desculpa para sumir — por isso o prazo é obrigatório |

### Recomendada
**C** (D aceitável só se o prazo e o dono ficam explícitos).

### Comportamento esperado
SAC fecha o ciclo; CX não lança $ sozinho; sem culpar pessoa em público.

### Evidência observável
“Confirmou relato; abriu checagem; informou retorno; escalou $ / encerrou com passo datado.”

### Contestação
Acusar pessoa sem fato → suspensa.

### Tom
Treino de recuperação — **não** caça a quem “errou o kit”.

## CASE-PROT-02 — Pico, “cadê?” e contexto

| Campo | Conteúdo |
|---|---|
| Base | E01 + pico · F1 · P10/P8 |
| Funções | DJ–DS · AO · LE |
| Comp | C-T03 · C-DS03 |
| Tempo | **8–10 min** |

### Contexto
19h. Bancada cheia. “Cadê?” na praça. Um pedido quase pronto; um multi-praça trava.

### Disponível / ausente
**Há:** pico, fila visível, 5 critérios de prioridade.  
**Não há:** ETA exato; de qual pedido é o grito.

### Opções
| # | Opção | Risco |
|---|---|---|
| A | Gritar “cadê?” mais alto | Caos |
| B | Parar a praça para discurso | Fluxo piora |
| C | Estado + impacto + ação; prioriza pelo critério (ex. quase pronto se aplicável) | 20–40 s de clareza |
| D | Só o mais antigo, ignorando o quase pronto | **Parcial** se risco real no antigo |

### Recomendada
**C**.

### Comportamento esperado
Comunicação com contexto; prioridade ≠ volume da voz; sem expor colega.

### Evidência
Mensagem/fala com 3 elementos no pico.

### Anti-punição
Não usar o caso para ridicularizar quem falou “cadê?” — ensinar o padrão melhor.

## CASE-PROT-03 — Colaboração com responsabilidade *(positivo)*

| Campo | Conteúdo |
|---|---|
| Base | B01/B03 · F1 · P5 |
| Funções | DJ · DP · DS |
| Comp | C-T02 · C-DJ03 |
| Tempo | **8–10 min** |

### Contexto
Pico. Dono designado. Colega ajuda. Kit ainda pendente.

### Opções
| # | Opção | Risco |
|---|---|---|
| A | Colega fecha sozinho e some | Sem dono |
| B | Dono rejeita qualquer ajuda | Perde capacidade |
| C | Confirma em voz alta quem fecha; ajuda com dono claro; confere kit | 10 s de alinhamento |
| D | Os dois conferem em silêncio sem nomear dono | **Parcial** — melhor que A, ambíguo sob pressão |

### Recomendada
**C**.

### Comportamento esperado
Ajuda + propriedade + qualidade. **Reconhecer** como evidência positiva se observado de verdade.

### Evidência
“Ajudou; confirmou dono; kit conferido antes de grampear.”
