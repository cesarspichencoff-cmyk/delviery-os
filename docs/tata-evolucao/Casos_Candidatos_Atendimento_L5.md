## REV-CASE-001 — Omissão / item incompleto (percepção)

| Campo | Conteúdo |
|---|---|
| situação | Cliente relata item principal ou parte do combinado ausente |
| expectativa | Pedido completo conforme cardápio |
| problema percebido | item_faltante |
| evidência | Avaliação com texto · nota baixa/média |
| opções | Reenvio · crédito · desculpas · investigação de conferência |
| resposta dada | **Desconhecida** (não no export) |
| resultado | Desconhecido |
| princípio | Excelência em atendimento · conferência |
| risco | Perda de confiança · recompra |
| aprendizado | Protocolo de kit/itens de alto giro na sacola |
| validação César | Sim |

**Destinos:** formação · conferência · embalagem · autonomia

## REV-CASE-003 — Frescor / qualidade percebida

| Campo | Conteúdo |
|---|---|
| situação | Relato de peixe “não fresco”, aparência ou gosto inadequado |
| expectativa | Padrão de qualidade consistente com visitas anteriores |
| problema percebido | qualidade_alimento (percepção) |
| evidência | Texto + nota ≤3 |
| opções | Escuta · verificação de lote/produção · recuperação comercial se política permitir |
| resposta | Desconhecida |
| princípio | Cultura de qualidade · não defensiva |
| risco | Segurança alimentar se sintomas; **revisão humana** se severidade crítica |
| aprendizado | Linguagem de resposta que valida percepção sem admitir o não verificado |
| validação César | Sim |

**Destinos:** formação · produção · atendimento
