# Boas Práticas — WhatsApp L1

> O sistema aprende também com o que **funcionou**.  
> ~97 unidades com sinal de `boa_solucao` (heurística); ideias de melhoria ~264.  
> Lista qualitativa — não ranking de pessoas.

---

## 1. Boas práticas candidatas (comunicação e operação)

| ID | Prática | Por que vale | Onde ensinar |
|---|---|---|---|
| BP-01 | Comunicar problema **com fato** (o que ocorreu + impacto) | Reduz ida e volta | Escalonamento · liderança |
| BP-02 | Recuperar pedido cedo (detectar antes do cliente gritar) | Menor dano | Conferência · júnior/pleno |
| BP-03 | Colaboração entre postos (“eu resolvo X, você Y”) | Velocidade sem herói único | Cultura · sênior |
| BP-04 | Antecipar pausa de item quando a praça não sobe | Evita cancel/erro | Liderança · assistência |
| BP-05 | Avisar atraso com honestidade (sem prometer o impossível) | Confiança do cliente | Atendimento |
| BP-06 | Registrar/compartilhar aprendizado (“da próxima…”) | Combate não-retenção | Cultura · casos |
| BP-07 | Sugerir melhoria de processo/app com problema concreto | Evolução | Cultura · pipeline de ideias |
| BP-08 | Criar canal de coordenação para decisões do delivery | Estrutura > caos de DMs soltas | Liderança |
| BP-09 | Pedir desculpas internas e focar correção (sem exposição pública) | Respeito | Cultura |
| BP-10 | Fechar o loop: “resolvido / cliente ok / falta treinar” | Resultado explícito | Assistência · liderança |

---

## 3. Como usar na Academia

- Cada BP vira **vinheta positiva** (1 tela: situação → ação → efeito).  
- Parear com caso de falha do mesmo tema (ex. BP-02 + WA-CASE-001).  
- Avaliar por **comportamento/consistência**, não por likes no grupo.  

---

## 4. Limitação

Heurística `boa_solucao` é subdetecção (muitas recuperações não usam palavras detectáveis).  
Revisão humana na B1+ pode ampliar o banco positivo.
