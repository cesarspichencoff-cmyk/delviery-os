## Top 10 prioritários

### WA-CASE-001 — Omissão de item / combinado na saída

| Campo | Conteúdo |
|---|---|
| case_id | WA-CASE-001 |
| Princípio | Qualidade · responsabilidade · padão de conferência |
| Situação (anon.) | Após o despacho, identifica-se que um item central do pedido não saiu |
| Opções | Reenvio · cortesia · investigar lacre · só registrar |
| Risco | Cliente · custo · reputação |
| Evidência | Unidades `item_faltante` recorrentes em múltiplos meses |
| Resultado | Variável / muitas vezes desconhecido no chat |
| Aprendizado | Checklist de âncoras (combinado/kit) antes do lacre |
| Curso possível | Cultura + operação de conferência |
| Validação César | Confirmar se ainda é top erro 2026 |
