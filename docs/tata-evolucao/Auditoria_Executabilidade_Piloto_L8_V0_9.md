| Premissa | Valor de teste |

## 2. Carga estimada (candidata)

### Funcionário (min/semana)

| Atividade | Min estimados | Notas |
|---|---|---|
| 2–3 microlições | 15–24 | 5–8 min cada |
| 1 caso / simulação | 10–15 | |
| Aplicação consciente no turno | 0–10 | embutido |
| Feedback pulse | 3 | |
| **Total** | **~30–50** | Alinhado ao plano L8 se **cortar** módulos |

Se L8 “cheio” (F1 14 + F2 15 + casos 36): **>90 min/sem** → **inviável** sem dropar qualidade.

### Líder (min/semana) — N=12

| Atividade | Min estimados |
|---|---|
| Brief 3 min × 5 dias | 15 |
| Validar 12×B (5 min) | 60 se 1/pessoa/sem |
| Debrief / captura caso | 15–20 |
| Correções de fila | 10–20 |
| **Total** | **~100–120** |

**Gargalo #1: LE.** Se 2 validações/pessoa/sem → dobra e quebra.

### César (min/semana piloto)

| Atividade | Min |
|---|---|
| Exceções $ / pausa loja / rejeições | 30–60 variável |
| Revisão semanal go/no-go conteúdo | 20–40 |

Ausência de 1 semana: LE opera com protocolos já aprovados; **sem** novos oficiais; $ “sempre escalar”.

## 5. Pontos de gargalo (ordem)

1. **Validação LE** (tempo + favoritismo).  
2. **César $** se limites não definidos.  
3. **Produção de conteúdo** se tentar 36 casos + 4 formações.  
4. **Comunicação de mudança** de protocolo no meio do piloto.  
5. **Percepção de punição** se só falhas forem registradas.
