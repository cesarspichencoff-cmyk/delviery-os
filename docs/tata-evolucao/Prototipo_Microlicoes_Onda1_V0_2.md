## MICRO-01 — Estado, impacto e ação necessária

| Campo | Conteúdo |
|---|---|
| **Duração** | **5–6 minutos** |
| **Formação** | F1 |
| **Competência** | C-T03 |
| **Protocolo** | P10 |

### Pergunta inicial
O que a operação precisa ouvir — além de pressão — para decidir o próximo passo?

### Situação
Pico. Bancada trava. Alguém grita “cadê?” para Quentes. Ninguém sabe de qual pedido nem o que está bloqueado.

### Princípio
**Estado conhecido + impacto no fluxo + ação necessária.**  
Desconhecido se declara como desconhecido.

### Anti-punição (visível)
Esta ferramenta **não** serve para expor ou acusar pessoa.  
Objetivo: permitir **decisão** e proteger o **fluxo**.  
Não usar no meio do pico para “corrigir o tom” de alguém.  
Feedback sobre comunicação — se precisar — no momento adequado (pós-pico / debrief), com fato, sem humilhar.

### Explicação curta
1. O que **já sabemos**?  
2. O que isso **bloqueia**?  
3. O que **precisamos** de volta (previsão, reforço, prioridade)?  

Exemplo conceitual (não frase obrigatória):  
*“O pedido está aguardando Quentes, bloqueia a conferência e precisa de uma previsão.”*

### Erro comum
“Cadê?” vazio · inventar ETA · usar a cobrança para constranger.

### Escolha
| # | Opção |
|---|---|
| A | “Cadê os quentes???” |
| B | “2 pedidos aguardam Quentes na bancada; bloqueia expedição; preciso de previsão.” |
| C | “Já está saindo” (sem checar). |
| D | Silêncio total. |

### Feedback
**B** recomendada. **A** pressão sem decisão. **C** hipótese. **D** não protege o fluxo se você pode comunicar.

### Aplicação
Uma troca hoje: estado + impacto + ação (ou “não sei ainda; chequei X”).

### Evidência possível
Fala/mensagem com os 3 elementos **ou** desconhecido explícito.

### Resumo
**Clareza serve ao fluxo — não à exposição.**

## MICRO-02 — Todos ajudam, uma pessoa fecha o ciclo

| Campo | Conteúdo |
|---|---|
| **Duração** | **5–6 minutos** |
| **Formação** | F1 |
| **Competência** | C-T02 · C-DJ03 |
| **Protocolo** | P5 |

### Pergunta inicial
Se vários ajudam, quem garante kit, lacre e fechamento?

### Situação
Três pessoas montam o mesmo pedido “pra ir rápido”. Na saída, ninguém sabe se o kit entrou.

### Princípio
**Todos podem ajudar. Uma pessoa fecha o ciclo** até transferência **explícita**.

### Explicação curta
Dono = posição no fluxo crítico.  
Ajuda ≠ transferência.  
Transferência = dizer e confirmar.  
Qualidade antes de “sair de qualquer jeito”.

### Erro comum
“Eu só ajudei” · aceno sem confirmação · grampear sem dono.

### Escolha
| # | Opção |
|---|---|
| A | Monta, grampela, some. |
| B | Ajuda e grita “alguém vê”. |
| C | Ajuda; confirma dono ou transferência explícita; confere com quem fecha. |
| D | Não ajuda para “não se meter”. |

### Feedback
**C** recomendada. **B** parcial. **A** alto risco. **D** perde capacidade.

### Aplicação
Confirmar dono na primeira sacola; se ajudar, confirmar se a responsabilidade mudou.

### Evidência possível
Nomeou dono / transferiu em voz alta / conferiu com quem fecha.

### Resumo
**Ajuda encurta; o dono (ou quem recebeu a passagem) fecha.**

## MICRO-03 — Investigar, recuperar e fechar *(reescrita)*

| Campo | Conteúdo |
|---|---|
| **Duração** | **5–6 minutos** |
| **Formação** | F2 |
| **Competência** | C-SAC01–04 · C-CX04 |
| **Protocolo** | P2 · P6 tipos |

### Pergunta inicial
Cliente diz que faltou item. O que é **fato** agora — e o que ainda é só percepção?

### Situação
Pedido saiu. Cliente no canal: faltou item. Caixa pergunta se “já pode descontar”. Causa ainda não confirmada.

### Princípio
Ouvir a percepção. Confirmar o conhecido. Não inventar causa.  
**SAC** conduz a relação e o fechamento.  
**Caixa** executa movimento financeiro **só se autorizado**.  
Qualquer compensação monetária / voucher / desconto / crédito / estorno **comercial** exige **autorização da liderança**.  
**LIMITES FINANCEIROS PENDENTES DO CÉSAR** — não usar valores.

### Fluxo simples (não roteiro rígido)

```text
ouvir
  → confirmar o conhecido
  → definir próximo passo
  → escalar quando necessário
  → acompanhar
  → fechar o ciclo
```

| Momento | O que fazer |
|---|---|
| Ouvir | Reformular o problema do cliente |
| Confirmar | O que já é fato (saiu? item alegado?) vs hipótese |
| Próximo passo | Investigar / retornar em X min / pedir evidência se útil **sem** abandonar |
| Escalar | $ ou exceção → liderança; produção se checagem interna |
| Acompanhar | Dono do ciclo até resposta |
| Fechar | Resultado ou próximo passo datado — ciclo não fica no ar |

### Erro comum
Desconto na hora · culpar colega sem fato · “vamos ver” sem dono nem horário.

### Escolha
| # | Opção |
|---|---|
| A | Autoriza desconto e encerra. |
| B | “Vamos ver” sem prazo. |
| C | Confirma relato; separa fato/hipótese; define retorno; escala $ se preciso; fecha ou data o passo. |
| D | “Só com foto” e some se não mandar. |

### Feedback
**C** recomendada. **D** pode pedir evidência **dentro** de C, não no lugar do ciclo. **A** viola $ provisória. **B** ciclo aberto.

### Aplicação
Antes de falar em compensação: uma linha mental — fato | hipótese | próximo passo.

### Evidência possível
Ciclo com fato · passo · (se $) autorização · aberto/fechado. Registro 30–45 s.

### Resumo
**Recuperar é fechar com dono; dinheiro só com liderança até existirem limites oficiais.**
