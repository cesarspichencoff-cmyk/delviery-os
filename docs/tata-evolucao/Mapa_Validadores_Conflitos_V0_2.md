> Matriz pequena. Substitutos. Conflito DS×AO. César.  
> Segregação: **não** criar + validar + aprovar sozinho evidência **sensível**.

## 1. Matriz-base

| Tipo de competência / evidência | Observa | Valida | Substituto | Conflito → | César quando |
|---|---|---|---|---|---|
| DJ/DP: sacola, kit conferência, montagem (C-DJ*, C-DP*, C-T02) | DS, AO, LE | **DS** | Outro DS · AO se DS ausente | LE | Amostra / sensível |
| Comunicação operacional C-T03 (não acusação) | DS, AO, LE | **DS** ou **AO** | LE | LE | Amostra |
| Protocolo básico P2/P4/P5 no chão | DS, AO | **DS** / **AO** | LE | LE | — |
| Fluxo, gargalo, escala multi C-DS03/04 | DS, AO, LE | **AO** ou **DS** | LE | LE | Se impacto grave |
| Ciclo SAC C-SAC* (sem $) | LE, DS | **LE** (ou DS se treinado no escopo) | LE backup | César se travar | Amostra |
| Execução $ CX C-CX04 | LE, CX lead | **LE** (autorização) | César | César | Sempre se exceção comercial |
| Autonomia ampliada / consistência C | LE | **LE** | César | César | Amostra C |
| LE / PL / dossiê / promoção | César | **César** | — | César | Sempre |
| Acusação a pessoa / disciplina disfarçada | — | **Não valida no TE** | — | César | Processo externo |
| Evidência insuficiente | qualquer | Marca **insuficiente** | — | LE | Se pedido |

### Status possíveis da evidência
`rascunho` · `em_revisao` · `aprovada` · `devolvida` · `insuficiente` · `suspensa` (contestação) · `corrigida`

**Insuficiente:** ninguém é “prejudicado”; só falta fato. Reobservar depois.

## 2. Papéis resumidos

| Papel | Escopo |
|---|---|
| **DS** | DJ/DP no chão: sacola, comunicação operacional, protocolo básico |
| **AO** | Fluxo, escalonamento, coordenação, protocolos no turno — **não** é LE |
| **LE** | Autonomia ampliada, C, exceções, **conflitos entre validadores**, impacto alto |
| **César** | LE, PL, dossiê, sensível, amostragem, impasse da LE |

---

## 3. Conflito DS × AO (oficial)

```text
1. Evidência status → em_revisao
2. Cada validador registra SÓ fato observado (1 linha cada)
3. LE verifica contexto (pode perguntar a um terceiro no turno)
4. LE: valida | devolve | insuficiente
5. Sem fato suficiente → insuficiente (sem prejuízo a pessoa)
6. Divergência ≠ personalidade ≠ disciplina
7. Histórico: duas linhas + decisão LE (auditável em papel)
```

Tempo alvo: **≤ 5 min** no dia; se não houver fato, encerra insuficiente.

---

## 4. Segregação sensível

Evidência **sensível** = envolve $ comercial, acusação nominal, segurança alimentar grave, ou uso potencial disciplinar.

| Proibido | Obrigatório |
|---|---|
| Mesma pessoa cria + valida + aprova sozinha | Segundo olho (LE ou César) |
| Validar o que só se “ouviu dizer” | Fato observado ou insuficiente |

---

## 5. Quando César participa

- Validação de LE/PL.  
- Dossiê.  
- Impasse LE.  
- $ / exceção comercial.  
- Amostragem (ex.: 1–2 evidências/sem no piloto).  
- Qualquer cheiro de disciplina no TE → redireciona para processo externo.

## 6. Ausências

| Ausente | Cobertura |
|---|---|

| AO | DS · LE |
| LE | LE backup · adia autonomia ampliada e C · $ com LE backup ou freeze se nenhum |
| César 1 semana | Freeze oficiais novos; $ com LE; sem mudar regra |
