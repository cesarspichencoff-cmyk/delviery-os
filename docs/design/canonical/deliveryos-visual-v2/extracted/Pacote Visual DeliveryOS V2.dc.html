Recomendação final, uma direção só

Consciência editorial. A tela é uma superfície de leitura, não um painel. A pressão aparece por hierarquia, ritmo e linguagem, nunca por medidores. Uma única atenção soberana, uma única ação. O que é confiável aparece cheio; o que envelheceu, desconectou ou falhou aparece desbotado, tracejado ou interrompido.

Por que esta e não outra
  • Confiança: distingue na hora dado confiável de dado velho.
  • Adoção: sem jargão, sem treino, leitura imediata sob pressão.
  • Identidade: parece feita para o Tatá, não um SaaS genérico.
  • Manutenção: uma superfície e poucos componentes.

Espaço e hierarquia

Escala 4px. Respiro generoso é regra, não sobra. Uma superfície central, uma voz dominante, uma ação. O silêncio é conteúdo: não se preenche a tela para evitar vazio.

Mobile-first

A lógica nasce no mobile, para consulta rápida em movimento. Nada essencial some para caber: título, sinal, ação e restrição sempre presentes. O desktop dá mais respiro para observação contínua, não estica o card.

A linha de sinal, por variante

A linha comunica a saúde da verdade operacional pela forma, nunca só pela cor. Ela apoia o texto, nunca fala sozinha, e nunca vira medidor, gráfico ou barra de desempenho.

05

Preservar e remover na implementação

Preservar

  • ✓ Fundo claro, verde escuro Tatá e tipografia editorial.
  • ✓ Foco único soberano, com uma só ação.
  • ✓ Linguagem humana e hora do último dado confiável.
  • ✓ Soberania do motor: a UI não escolhe nem recalcula o foco.
  • ✓ Silêncio visual quando nada exige atenção.

Remover

  • ✕ O anel-medidor e o grande "0" do Calmo.
  • ✕ Os seis cards de Ambiente, com borda, barra e porcentagem.
  • ✕ As três colunas do Foco e o conteúdo repetido.
  • ✕ O texto técnico genérico único para todos os estados.
  • ✕ Rótulos de simulador dentro da superfície do produto.
Fecho

Direção recomendada definida, dezesseis pranchas cobertas, sistema mínimo documentado. Nenhum código alterado, nenhuma implementação declarada. Pronto para validação do César.
