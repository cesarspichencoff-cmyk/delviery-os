# Acessibilidade — 3C.1

- Foco visível (`:focus-visible`)  
- Labels / `aria-label` / `role="status"` / `role="alert"`  
- Alvos ≥ 44px (console e mobile)  
- Não depende só de cor (chips + texto)  
- `prefers-reduced-motion`  
- Ordem de tab natural  
- Textos de erro em `role="alert"`  
- Zoom: layout fluido  

Limitações do protótipo: auditoria completa de leitor de tela em gate futuro de QA.
