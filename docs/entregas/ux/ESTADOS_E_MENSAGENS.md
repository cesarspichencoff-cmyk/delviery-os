# Estados e mensagens de UI

| Situação | Mensagem / tratamento |
|---|---|
| Lista vazia | “Nenhuma viagem neste filtro” ≠ erro |
| Carregando | “Carregando…” |
| Erro domínio | `error-box` com texto do ApplicationService |
| Offline | chip Offline + pending_sync |
| entrega_sem_confirmacao | “Aguardando confirmação” (não acusatório) |
| Sem GPS | “Localização indisponível” — não desenha motoboy |
| Demo | Banner fixo AMBIENTE DE DEMONSTRAÇÃO |
