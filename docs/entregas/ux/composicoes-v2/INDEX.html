Problemas da referência histórica (app-v1) que não serão repetidos

  • Tabela / listagem como rosto do produto
  • Densidade de painel logístico sem respiro editorial
  • Vários botões primários equivalentes
  • Tipografia system como padrão
  • Cards de KPI / porcentagem como “ambiente”
  • Mapa stock do provedor como identidade
  • Declarar parentesco só porque as cores batem
