# Segurança de alergênicos

Estados distintos:

| Estado | Interpretação |
|---|---|
| `not_listed_in_recipe` | não consta; não é garantia |
| `does_not_contain_approved_source` | ausência confirmada por fonte aprovada |
| `cross_contact_possible` | incompatível para recomendação segura |
| `contains` | incompatível |
| `unknown` | exige confirmação humana |

Uma alergia declarada elimina qualquer item que contenha o alérgeno, possa ter
contato cruzado ou não possua informação aprovada suficiente. Conhecimento
genérico não completa camarão, peixe, soja, glúten, lactose ou gergelim.

O DOCX externo contém agrupamentos que precisam de revisão, inclusive uma
sugestão “glúten-free” com tempurá. Nenhuma dessas afirmações foi promovida a
garantia. Na dúvida, o painel retorna “nenhuma opção segura confirmada”.
