# Fechamento de turno

`src/copiloto/shift-closing.js`

## Regras
- Ideal 60s, máximo 120s
- 0–3 perguntas
- Não perguntar o que os dados já respondem
- Priorizar ganho de informação
- Opções: não sei / pular
- Sem formulário longo
- Sem análise emocional

## Fluxo de áudio
resumo → pergunta → transcrição → confirmação → próxima → resumo final → salvar
