# Princípios de Conteúdo e Microcopy — Entregas V0.1

---

## 1. Tom

| É | Não é |
|---|---|
| Direto, de expedição e rua | Corporativo / BI |
| Calmo sob pressão | Sirene / culpa |
| Fato e próxima ação | Produtividade individual |
| Curto no mobile | Manual longo |

Família do DeliveryOS: **premium, calma, operacional** — adaptada à viagem.

---

## 2. Vocabulário

| Usar | Evitar |
|---|---|
| Viagem, parada, saída, retorno, fechamento | “Missão”, “drop”, jargão de app gringo no chão |
| Disponível / na loja (separados) | “Online” para pessoa |
| Confirmar entrega | “Finalizar” ambíguo |
| Não sincronizado ainda | “Erro seu” |
| Volumes | “Pacotes” se confundir com pedido |
| Exceção / ocorrência | “Falha do motoboy” |

---

## 3. Anatomia da mensagem

1. **O que está acontecendo** (estado da viagem/parada)  
2. **O que fazer agora** (CTA)  
3. **O que ainda não está comprovado** (se houver)  
4. **Limite** (offline, mapa indisponível)

---

## 4. Exemplos V0.1

| Contexto | Copy |
|---|---|
| Próxima ação | “Próximo: entregar · parada 2 de 4” |
| Confirmar | “Confirmar entrega · 2 volumes” |
| E01 | “Cliente não atendeu. Registrar tentativa e seguir ou retornar?” |
| Offline | “Sem conexão. A ação fica na fila até sincronizar.” |
| Fechamento pendente | “Retorno ainda não confirmado. Viagem não está fechada.” |
| Divergência | “Volumes não batem. Resolver antes de sair.” |
| Mapa off | “Sem mapa. Use a ordem das paradas e a referência.” |
| Disponibilidade | “Na loja — ainda não disponível para nova viagem.” |

---

## 5. Proibições de copy

- Ranking, “top rider”, “abaixo da média”  
- “Sempre” / “nunca atraso” com falsa precisão  
- Exigir desculpas do rider ao cliente via app  
- Texto longo durante deslocamento  

---

## 6. Epistemologia no texto

| Fato | Como dizer |
|---|---|
| Confirmado | “Entrega confirmada” |
| Pending sync | “Registrado no aparelho · aguardando envio” |
| Provisional return | “Retorno informado · falta confirmar na loja” |
| Sem GPS | “Localização indisponível · continue pela lista” |
